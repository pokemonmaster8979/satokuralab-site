OTP Hub Privacy Policy

Last updated: October 2026

OTP Hub is a personal application operated by SatoKura Lab.

Google user data

OTP Hub accesses Gmail messages for the purpose of detecting one-time passwords requested by the user.

Gmail data is not sold, shared with advertisers, or used for advertising.

Message contents are processed only as necessary to detect one-time passwords. The application stores only the minimum information required for its functionality.

Data sharing

Google user data is not transferred to third parties except where necessary to provide functionality explicitly requested by the user.

Contact

For questions regarding this privacy policy, please use the support contact shown on the application's Google OAuth consent screen.
